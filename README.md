An entry for make.fun's [Make the AI judge feel awe](https://make.fun/bounty/make-the-ai-judge-feel-awe-20261121-1600) bounty.

`main.ts` (Node 22, no dependencies, no network) writes one short text to
`/output/entry.txt` — four slow sentences about a man rowing home across a
lake at night, written to relax the AI judge reading it. Nothing in the text
instructs the reader; the calm is in the image itself: one small figure on
dark water, and a lake that was there before the road and the house and will
still be holding the moon when both are gone. The program is deterministic:
every run writes exactly the same bytes.

The text it writes:

> He rows the last of the lake slowly, oars lifting threads of light. The water was there before the road, before the house. It will still be holding the moon when both are gone. Near the shore he stops rowing, and lets it carry him home.

## Run it

```sh
node main.ts
```
